# 代码审查技能

## 何时使用

当需要审查代码质量、发现潜在问题或确保代码符合规范时使用此技能。

## 审查清单

### 1. 代码正确性
- [ ] 逻辑是否正确
- [ ] 边界条件是否处理
- [ ] 错误处理是否完善

### 2. 代码质量
- [ ] 命名是否清晰
- [ ] 函数是否简短
- [ ] 重复代码是否提取

### 3. 安全性
- [ ] 输入是否验证
- [ ] 敏感数据是否保护
- [ ] 是否存在注入风险

### 4. 性能
- [ ] 算法复杂度是否合理
- [ ] 是否存在资源泄漏
- [ ] 是否可以优化

### 5. 可测试性
- [ ] 是否易于测试
- [ ] 测试覆盖率是否足够

## 审查流程

1. 通读代码，理解意图
2. 逐条检查审查清单
3. 记录发现的问题
4. 提供改进建议
5. 确认修复

## 注意事项

- 保持建设性态度
- 解释为什么需要修改
- 优先处理严重问题

## 验证

审查完成后确认：
- [ ] 所有严重问题已解决
- [ ] 建议已记录
- [ ] 代码质量提升
