# 研究技能

## 何时使用

当需要收集信息、分析数据或调研某个主题时使用此技能。

## 工作流程

1. **明确研究目标**
   - 确定需要回答的问题
   - 界定研究范围

2. **收集信息**
   - 使用 web_search 搜索相关资料
   - 使用 web_extract 提取关键内容
   - 记录信息来源

3. **分析整理**
   - 分类整理收集到的信息
   - 识别关键观点和趋势
   - 评估信息可信度

4. **生成报告**
   - 结构化呈现研究结果
   - 提供明确的结论和建议
   - 列出所有参考来源

## 注意事项

- 始终验证信息来源的可靠性
- 区分事实和观点
- 记录搜索关键词以便复现

## 验证

检查报告是否包含：
- [ ] 清晰的研究问题
- [ ] 充分的信息来源
- [ ] 逻辑严密的分析
- [ ] 明确的结论
