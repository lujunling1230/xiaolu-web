# 任务委派技能

## 何时使用

当任务复杂需要分解、或需要多个 Agent 协作完成时使用此技能。

## 委派流程

1. **分析任务**
   - 理解任务目标和约束
   - 评估复杂度
   - 识别依赖关系

2. **分解任务**
   - 拆分为独立的子任务
   - 确定执行顺序
   - 明确交付物

3. **选择 Agent**
   - 根据子任务类型选择 Agent
   - 考虑 Agent 负载
   - 确保技能匹配

4. **委派执行**
   - 清晰描述子任务
   - 提供必要的上下文
   - 设定完成标准

5. **监控进度**
   - 跟踪执行状态
   - 处理阻塞和异常
   - 协调资源

6. **汇总结果**
   - 收集各子任务结果
   - 验证完整性
   - 整合输出

## 委派原则

- 子任务应尽可能独立
- 明确输入输出接口
- 设置合理的超时时间
- 保留回退方案

## 注意事项

- 避免过度分解
- 关注关键路径
- 及时沟通异常

## 验证

委派完成后检查：
- [ ] 所有子任务已完成
- [ ] 结果符合预期
- [ ] 没有遗漏的依赖
