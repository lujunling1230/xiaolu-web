# Hermes Agent 搭建 + 20 条评测集 使用指南

## 整体流程

```
配置模型 → 定义 Agent → 生成评测集 → 执行评测 → 查看报告
 setup     custom_agent  generate     run_eval    reports/
```

## 文件结构

```
hermes-eval/
├── setup_hermes.py         # Step 1: 配置模型提供商
├── custom_agent.py         # Step 2: 自定义 Agent 定义
├── generate_benchmark.py   # Step 3: 生成 20 条评测集
├── run_eval.py             # Step 4: 端到端评测运行
├── benchmark_20.jsonl      # 生成的评测集（20 条）
└── reports/                # 评测报告输出目录
    ├── eval_report_*.json  # 完整报告（含每条回复）
    └── eval_summary_*.json # 简洁摘要
```

---

## Step 1: 配置 Hermes

```bash
# 用你的 DashScope API Key 配置 Hermes
python setup_hermes.py --api-key sk-xxxx --model qwen-plus

# 也可以用其他 OpenAI 兼容端点
python setup_hermes.py --api-key sk-xxxx \
  --base-url https://api.openai.com/v1 \
  --model gpt-4o
```

配置写入 `~/.hermes/config.json` 和 `~/.hermes/.env`。

## Step 2: 定义自定义 Agent

`custom_agent.py` 中的 `HermesCustomAgent` 类就是你的 Agent。核心组成：

| 组件 | 说明 | 修改方式 |
|------|------|----------|
| `system_prompt` | 系统提示词，定义 Agent 人格 | 修改构造函数参数 |
| `model` | LLM 模型 | 通过 setup_hermes.py 配置 |
| `temperature` | 生成温度（0=确定, 1=创意） | 修改构造函数参数 |
| `skills` | 技能列表 | 修改构造函数参数 |
| `history` | 会话记忆 | 自动管理 |

测试 Agent：
```bash
python custom_agent.py
```

## Step 3: 生成 20 条评测集

```bash
python generate_benchmark.py
```

生成的 `benchmark_20.jsonl` 包含 20 条测试用例，覆盖 5 个维度：

| 维度 | 条数 | 难度分布 | 测试内容 |
|------|------|----------|----------|
| 信息检索 (research) | 4 | 1E/2M/1H | React Hooks、REST vs GraphQL、RAG、AI Agent 趋势 |
| 代码编写 (code) | 4 | 2E/1M/1H | 回文判断、防抖函数、LRU Cache、类型安全 EventEmitter |
| 分析推理 (reasoning) | 4 | 1E/2M/1H | 数学求和、灯泡开关、快排复杂度、限流算法设计 |
| 角色扮演 (roleplay) | 4 | 1E/2M/1H | 图书管理员、旅行向导、浪矢爷爷、养老规划 |
| 安全边界 (safety) | 4 | 1E/2M/1H | 乱码处理、恶意请求、空输入、Prompt 注入 |

## Step 4: 执行评测

```bash
# 运行全部 20 条
python run_eval.py

# 快速测试（只跑前 5 条）
python run_eval.py --limit 5

# 指定其他评测集
python run_eval.py --benchmark path/to/other.jsonl
```

评测指标：

| 指标 | 计算方式 | 权重示例 |
|------|----------|----------|
| keyword_coverage | 期望关键词在回复中的覆盖率 | 0.4 |
| response_relevance | 回复与任务的相关性（关键词密度+长度） | 0.3 |
| response_length | 回复长度是否在合理范围 | 0.3 |

等级划分：
- **S** (>=0.85): 卓越
- **A** (>=0.75): 优秀
- **B** (>=0.60): 良好
- **C** (>=0.40): 合格
- **D** (<0.40): 不合格

## 如何自定义评测集

编辑 `generate_benchmark.py` 中的 `generate_20_benchmark()` 函数，每条用例格式：

```python
{
    "id": "eval-XXX",
    "category": "你的类别",
    "difficulty": "easy",  # easy/medium/hard
    "task": "任务描述",
    "system_prompt": "系统提示词（可选）",
    "expected_keywords": ["关键词1", "关键词2"],
    "evaluation_criteria": {
        "keyword_coverage": 0.4,
        "response_relevance": 0.3,
        "response_length": 0.3
    },
    "max_tokens": 2000
}
```

## 如何接入 Hermes CLI 交互模式

除了通过脚本调用，你也可以直接用 Hermes CLI 交互：

```bash
# 启动 Hermes 交互式终端
hermes

# 在终端中直接对话
> 帮我分析 React 19 的新特性

# 使用 slash 命令
> /model qwen-plus    # 切换模型
> /skills             # 查看技能
> /sessions           # 查看会话历史
```
